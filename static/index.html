Save and find

Hybrid BM25 + vectors with RRF, reranking, source/date metadata and passage citations remain available. Ask your saves uses the agent retrieval path and query rewriting.

Agents and tools

LangGraph supervisor, retriever, writer and verifier; a repair loop, persistent checkpoints, memory and four typed MCP servers. Ask your saves shows the plan and source evidence.

Notebook writes still pause for approve, edit or reject. Approval is bound to the exact payload; creating a private search index does not require a second approval.

Evidence still to complete

30+ labelled search queries; 60+ reviewed evaluation cases; independent judge calibrated on 20+ human labels; baseline/team and memory comparisons; reviewed Reflexion lessons; 30+ red-team attacks; clean deployment, monitoring alert and CI demonstrations.

Existing code and synthetic fixtures are preparation, not proof of real-video accuracy. The team must run and report the experiments.
